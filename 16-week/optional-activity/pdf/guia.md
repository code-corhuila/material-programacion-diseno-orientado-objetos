# GUÍA DE ACTIVIDAD PRÁCTICA

**Programación y Diseño Orientado a Objetos · Semana 16 · Portafolio y reflexión final**

| Programa | Ingeniería de Sistemas | Asignatura | Programación y Diseño Orientado a Objetos |
|---|---|---|---|
| Unidad | Unidad 3 · Robustez y bibliotecas | Semana / Corte | 16 · Corte 3 |
| Modalidad | Individual o en parejas | Periodo | 2026-B |
| Tipo | Formativa (opcional, sin nota) | Entrega | Repositorio en GitHub |

## Objetivos

- Pulir el proyecto final y su documentación.
- Aplicar la retroalimentación recibida.
- Reflexionar sobre el aprendizaje del semestre.

## 1. Enunciado

1. Aplica la **retroalimentación** recibida a tu proyecto final.
2. Pule el repositorio: README claro, commits ordenados, código limpio.
3. Escribe una **reflexión** (media página): concepto más difícil, lo que más te enorgullece, qué mejorarías.
4. **Destaca** (fija) el repositorio en tu perfil de GitHub.

## 2. Requisitos

- Ajustes de retroalimentación aplicados.
- README final claro con el diseño.
- Reflexión personal incluida.

## 3. Cómo entregar

Entrega **por GitHub**. Repositorio: `poo-proyecto-final` (versión final).

```
poo-proyecto-final/
  README.md   -> version final + reflexion
  src/         -> proyecto pulido
```

1. Actualiza el repo con la versión final.
2. Añade la reflexión al README.
3. Comparte el enlace por el canal indicado.

## 4. Rúbrica de evaluación

| Criterio | Excelente | Aceptable | Por mejorar | Pts |
|---|---|---|---|---|
| Retroalimentación aplicada | Completa | Parcial | Ausente | 30 |
| Proyecto pulido (código + README) | Ordenado y claro | Aceptable | Deficiente | 35 |
| Reflexión | Profunda | Básica | Ausente | 35 |
