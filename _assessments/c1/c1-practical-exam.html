Parcial práctico · Corte 1

Semana 5 del corte. Evaluación individual, en clase o por GitHub (en tu fork del repositorio de la clase). Valor: 5.0. Se evalúa el razonamiento y el diseño, no solo que compile. Temas del corte (encapsulamiento, constructores, identidad).

Problema 1 — Clase encapsulada con invariante (2.0)

Implementa Temperatura (grados Celsius) que nunca permita un valor por debajo de −273.15 (cero absoluto). Usa atributo privado, validación en constructor y en el setter (o hazla inmutable). Incluye 2 pruebas que demuestren el rechazo de valores inválidos.

Problema 2 — Identidad (equals/hashCode) (2.0)

Implementa Producto (código, nombre) con equals() y hashCode() basados en el código. Demuestra que dos productos con el mismo código son equals y funcionan como clave en un HashSet (no se duplican).

Problema 3 — Referencias y aliasing (1.0)

Escribe un fragmento donde dos variables apunten al mismo objeto y muestra el efecto del aliasing. Explica en comentarios cómo evitarlo (copia defensiva o inmutabilidad).

English requirement (20%)

For Problem 2, write 2–3 sentences in English explaining the equals/hashCode contract (equal objects must have the same hash code).

Cómo entregar

Entrega en tu fork del repositorio de la clase, dentro de la carpeta de la semana correspondiente. Sigue el Manual de Entrega por GitHub (Información importante): fork → clonar → agregar tu trabajo → git add/commit/push. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
