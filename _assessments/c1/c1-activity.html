Actividad calificable · Corte 1 — Clase encapsulada en Java

Semana 4 del corte. Entrega individual por GitHub. Entrega en tu fork del repositorio de la clase. Valor: 5.0.

Enunciado
  1. Implementa una clase CuentaBancaria con atributos privados (titular, saldo) e invariante saldo ≥ 0.
  2. Añade constructores (uno completo y otro que use this(...)) y métodos depositar/retirar que validen (no permitir saldo negativo ni montos ≤ 0).
  3. Sobrescribe toString(), y equals() + hashCode() de forma coherente (p. ej. por número de cuenta).
  4. En el main, demuestra la validación y que equals funciona.
Requisito en inglés (20%)

Sección del README "Design decisions" (mínimo 5 oraciones, en inglés): explica encapsulation, invariants y el contrato equals/hashCode.

Cómo entregar

Entrega en tu fork del repositorio de la clase, dentro de la carpeta de la semana correspondiente. Sigue el Manual de Entrega por GitHub (Información importante): fork → clonar → agregar tu trabajo → git add/commit/push → Pull Request si el docente lo pide. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
