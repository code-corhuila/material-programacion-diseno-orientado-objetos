Proyecto final · Corte 3 — Sistema orientado a objetos completo

Semana 15–16. Entrega individual o en pareja por GitHub. Entrega en tu fork del repositorio de la clase. Valor: 5.0. Es la síntesis del semestre.

Enunciado

Construye una aplicación de consola en Java para un problema real de gestión (biblioteca, inventario, turnos, playlist…) que integre:

  1. Los cuatro pilares: encapsulamiento, herencia o interfaces + polimorfismo, y composición.
  2. Colecciones (List/Map) + excepciones (incluida una propia) + CRUD completo.
  3. Persistencia en archivo aislada en un Repositorio (por capas: modelo / servicio / persistencia / app) y buenas prácticas (SOLID).
Requisito en inglés (20%)

Sección del README "Architecture & OOP" (mínimo 6 oraciones, en inglés): explica las clases, las relaciones y cómo aplicaste los pilares.

Cómo entregar

Entrega en tu fork del repositorio de la clase, dentro de la carpeta de la semana correspondiente. Sigue el Manual de Entrega por GitHub (Información importante): fork → clonar → agregar tu trabajo → git add/commit/push → Pull Request. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
