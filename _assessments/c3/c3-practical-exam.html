Parcial práctico · Corte 3

Semana 15 del corte. Evaluación individual, en clase o por GitHub (en tu fork del repositorio de la clase). Valor: 5.0. Temas del corte: excepciones, colecciones, archivos, buenas prácticas.

Problema 1 — Excepciones (2.0)

Implementa una Cuenta con retirar(double) que lance una excepción propia SaldoInsuficienteException si el monto supera el saldo. Maneja la excepción con try-catch y muestra un mensaje claro. Incluye 2 pruebas (caso válido e inválido).

Problema 2 — Colecciones (1.5)

Con un Map<String, Integer>, cuenta cuántas veces aparece cada palabra en una frase. Recorre el resultado con entrySet() e imprímelo. Explica por qué un Map encaja mejor que una List aquí.

Problema 3 — Archivos (1.5)

Guarda una lista de objetos en un archivo CSV y vuelve a cargarla (round-trip), aislando la lógica en un Repositorio y manejando IOException. Verifica que lo cargado coincide con lo guardado.

English requirement (20%)

For Problem 1, write 2–3 sentences in English explaining the difference between throw and throws, and when to create a custom exception.

Cómo entregar

Entrega en tu fork del repositorio de la clase, dentro de la carpeta de la semana correspondiente. Sigue el Manual de Entrega por GitHub (Información importante): fork → clonar → agregar tu trabajo → git add/commit/push. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
