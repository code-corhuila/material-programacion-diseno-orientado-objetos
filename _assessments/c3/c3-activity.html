Actividad calificable · Corte 3 — CRUD robusto con persistencia

Semana 14 del corte. Entrega individual por GitHub. Entrega en tu fork del repositorio de la clase. Valor: 5.0.

Enunciado
  1. Modela una entidad (p. ej. Producto) y gestiona una colección con un CRUD usando List o Map.
  2. Valida las operaciones lanzando una excepción propia (p. ej. ProductoNoEncontradoException).
  3. Persiste los datos en un archivo (CSV): guardar y cargar, con la lógica aislada en un Repositorio (SRP) y manejo de IOException.
Requisito en inglés (20%)

Sección del README "Exceptions & persistence" (mínimo 5 oraciones, en inglés): explica el manejo de excepciones y la separación del repositorio.

Cómo entregar

Entrega en tu fork del repositorio de la clase, dentro de la carpeta de la semana correspondiente. Sigue el Manual de Entrega por GitHub (Información importante): fork → clonar → agregar tu trabajo → git add/commit/push → Pull Request si el docente lo pide. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
