Actividad calificable · Corte 2 — Jerarquía polimórfica en Java

Semana 9 del corte. Entrega individual por GitHub. Entrega en tu fork del repositorio de la clase. Valor: 5.0.

Enunciado
  1. Define una clase abstracta Figura con método abstracto area() y un método concreto describir().
  2. Crea al menos 3 subclases (Circulo, Rectangulo, Triangulo) que sobrescriban area() con @Override.
  3. Define una interfaz Dibujable con dibujar() e impleméntala en las figuras.
  4. En el main, recorre un Figura[] y muestra área y dibujo de cada una (polimorfismo).
Requisito en inglés (20%)

Sección del README "Polymorphism & design" (mínimo 5 oraciones, en inglés): explica abstract class vs interface y dónde usas polymorphism.

Cómo entregar

Entrega en tu fork del repositorio de la clase, dentro de la carpeta de la semana correspondiente. Sigue el Manual de Entrega por GitHub (Información importante): fork → clonar → agregar tu trabajo → git add/commit/push → Pull Request si el docente lo pide. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
