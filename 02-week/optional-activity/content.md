## 1. Enunciado

1. Crea una clase `Libro` con atributos: `titulo`, `autor`, `paginas`.
2. Agrega un método `describir()` que imprima los datos del libro.
3. Agrega un método `esLargo()` que devuelva `true` si tiene más de 300 páginas.
4. En `main`, crea **3 libros** distintos, descríbelos e indica cuáles son largos.

## 2. Requisitos

- Clase con atributos y 2 métodos.
- Al menos 3 objetos instanciados.
- Uso correcto de `new` y del operador punto.

## 3. Cómo entregar

Entrega **por GitHub**. Repositorio: `poo-s02-clases`.

```
poo-s02-clases/
  README.md   -> como ejecutar + salida de ejemplo
  src/         -> Libro.java, Main.java
```

1. Crea el repo público con ese nombre.
2. Sube el código y el README.
3. Comparte el enlace por el canal indicado.
